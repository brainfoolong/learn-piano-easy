# Security policy

learn-piano-easy runs entirely in the browser. It has no server and no accounts, and it sends no data
anywhere. It reads MIDI files and MIDI devices you choose, and keeps its settings and songs in your
browser's storage.

## Supported versions

Only the latest release gets fixes.

## Reporting a vulnerability

Report it privately through GitHub's "Report a vulnerability" button on this repository's Security tab.
Please do not open a public issue for it. Describe the steps to reproduce it, and attach a sample file
when one triggers it. We answer within two weeks.

A crafted MIDI file that crashes or hangs the app counts as a vulnerability.
