# 0004: The site is in English and German, with typed catalogs and a page per locale

## Decision

- The site speaks English and German. English is at the site's root, and German is under `de/`.
- A locale is one message catalog, so a third language is one file and one line in the locale list.
- A catalog is a typed object. `src/i18n/messages/en.ts` defines its type, and every other catalog must
  satisfy it.
- A message with a number is a function over `Intl.PluralRules` and `Intl.NumberFormat`. No catalog
  holds a template language.
- The build writes one small page for every route in every locale. Each page carries its own title,
  description and `lang`, and links the shared bundle relative to its own depth.
- `src/site/routes.ts` is the one route table. The build writes the pages from it, and the router reads
  it.
- Canonical and `hreflang` links are written only when the build gets `--site-url`, so a local build
  names no domain.

## Why

Every link of the site must reload on any static host, at any base path and offline. A page per route
and locale needs no rewrite rule on the host. Its own `lang` and title serve a screen reader and a
search engine before any script runs.

A typed catalog lets the type checker refuse a missing message, so a missing translation never ships.
`Intl` already knows each language's plurals and number formats, and the browser ships it for free.

## Consequences

- The build writes many small pages, and the service worker caches each of them.
- The gallery at `design/` keeps its own bundle until the router takes it over.
- A lesson's pages join the route table once the course names its worlds and lessons.

## Rejected

- **One page with a rewrite rule on the host:** a static host or a file system cannot be told the rule.
  A reload of a deep link then fails there.
- **A hash router:** its links are not real addresses, and a page cannot carry its own title or `lang`.
- **An i18n package such as i18next:** a second runtime dependency, and a template language the type
  checker cannot see into.
- **Strings with placeholders:** a missing argument and a wrong plural show up only at run time.
