# The mascot's videos

The files in this folder show the site's mascot, our piano teacher. The project's maintainer made the
source video with Google Gemini, a video generator, for this project. They are under the MIT License,
the same as the app: see `LICENSE` at the repository root.

`tools/mascot-video.ts` cuts and encodes each file from that one source video.

| File | What it shows | License |
|---|---|---|
| `at-the-piano.mp4` | The mascot at an upright piano, pushing in to its face, 1024 by 576 pixels | MIT |
| `at-the-piano.webp` | The first frame of `at-the-piano.mp4`, its poster | MIT |
| `portrait.mp4` | The mascot's face in a loop, a square of 256 pixels | MIT |
| `portrait.webp` | The first frame of `portrait.mp4`, its poster | MIT |
