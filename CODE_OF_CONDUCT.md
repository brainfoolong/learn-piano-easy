# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
Its full text applies to every space of the project: issues, pull requests, discussions and chat.

## In short

- Be kind and patient. Many people here are learning, both piano and code.
- Criticise ideas, never people.
- Harassment, insults and unwelcome attention are not tolerated.

## Reporting

Report a problem to the maintainers through a private GitHub security advisory on this repository, or
by the contact the repository profile lists. Every report is read and kept confidential. The maintainers
act as the Contributor Covenant's enforcement guidelines describe.
